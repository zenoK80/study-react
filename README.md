# React 학습 정리

## Part 1. React 기초 & JSX
* **01_TestMission**: JSX와 React.createElement 동작 원리 및 가상 DOM 비교
* **02_react_rendering_process**: useState/useEffect 타이머를 활용한 가상 DOM 부분 업데이트
* **03_Hello**: 첫 컴포넌트 만들기, 파스칼케이스 규칙, Fragment(<>...</>) 사용법
* **04_Greeting**: Props 전달 기초 및 매개변수 구조 분해 할당
* **05_ProfileHeader**: 부품 컴포넌트(Emoji, Title 등) 조립 및 Props 재분배
* **06_ChildrenPractice**: children props 활용법 및 Card 래퍼 컴포넌트 패턴
* **07_ListRendering**: map/filter 체이닝, 고유 key 부여, 화살표 함수 반환 규칙 및 다중 검색 필터

## Part 2. 상태 관리 (useReducer)
* **01_Cafeteria**: useReducer 기초, dispatch와 action을 활용한 밥 재고 관리
* **02_ShoppingCart**: 객체/배열 상태의 불변성 유지, 장바구니 추가/삭제 및 총액 자동 계산
* **03_TicketBooking**: 액션 상수화, 좌석 선택 토글(최대 4개) 및 VIP 할인율 적용 로직
